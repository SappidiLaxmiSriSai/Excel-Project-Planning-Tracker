# Dynamic Excel Project Planning & Milestone Tracker

## Overview
An interactive, automated project management tracker built in Microsoft Excel to monitor project phases, track milestone dependencies, and automatically flag overdue deliverables.

## Key Features
* **Automated Status Logic:** Utilizes custom `IF` formulas and dynamic flags (`Auto Flag`) to detect overdue tasks based on target end dates.
* **Conditional Formatting:** Color-coded visual indicators for task completion, in-progress items, and priority flags.
* **Dynamic Executive Dashboard:** Summarizes task status, milestone progress, overdue task alerts, and priority breakdowns in real time.
* **Dependency & WBS Structure:** Tracks task dependencies (`Depends On`) and phase breakdowns across discovery and execution stages.
